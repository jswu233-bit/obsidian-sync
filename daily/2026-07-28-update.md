### 1. OpenAI：AI 正在扩大工作边界，而不是只替代单点任务

**发生了什么**  
OpenAI 发布《How AI is expanding what people do at work》，核心结论是 ChatGPT 用户正在跨角色承担更多任务，AI 让岗位边界发生变化，而不是简单把某个岗位整体替换掉。这个叙事和 OpenAI 近期连续发布的工作场景内容一致：从小企业、销售、数据科学，到 Codex 在企业事故分析里的落地，OpenAI 正在把“模型能力”包装成“可衡量的工作产出”。  
链接：https://openai.com/index/how-ai-is-expanding-what-people-do-at-work

**为什么重要**  
这类研究的价值不在于“AI 会不会改变工作”这种大命题，而在于它给企业采购和产品设计一个更可落地的口径：不要只看模型榜单，要看某类工作是否能被 AI 拆成可执行任务、是否能形成 ROI 度量。对产品经理来说，这意味着 AI 产品的竞争会从“回答质量”转向“任务闭环”：输入业务上下文、执行多步骤动作、留下可审计结果、按成本与成功率复盘。

**Zoe点评**  
我看多“按工作流定价”的 AI 产品，短期优先级上调。Jamie 如果要做 OpenClaw 相关产品，不要把卖点写成“更聪明的助手”，而应写成“把某个固定业务流程每天稳定跑完”：日报、竞品监控、促销复盘、支付异常归因，这些比泛聊天更容易拿到真实价值。

### 2. Perplexity 把 Personal Computer 扩到 Windows：本地电脑 Agent 进入主流平台竞争

**发生了什么**  
The Verge 报道，Perplexity 将 Personal Computer 扩展到 Windows，让 Windows PC 作为本地运行的 AI 系统，访问本地文件和应用来执行创建文档、更新表格等动作。它此前已在 Mac 上推出，并与 Microsoft 365、Teams 做过集成。  
链接：https://www.theverge.com/ai-artificial-intelligence/971750/perplexity-personal-computer-windows-ai-agents

**为什么重要**  
这不是普通聊天产品更新，而是 Agent 从浏览器标签页走向操作系统层的信号。Windows 是最大桌面入口，谁能在本地文件、Office、会议、邮件之间形成可靠动作链，谁就能更接近“企业个人工作台”。但它也会放大权限、安全和误操作问题：本地 Agent 不只是读网页，它会碰真实文件和工作应用。

**Zoe点评**  
方向看多，但短期建议谨慎跟进。OpenClaw 这类系统不该一上来追求“控制整台电脑”，更适合先做受限动作空间：固定目录、固定工具、固定审批点。明天可以优先研究“本地 Agent 权限边界”和“动作前审计卡片”，这是产品化关键。

### 1. AgentENV 爆火：Agent 基础设施开始从 demo 走向规模化训练环境

**发生了什么**  
GitHub 新项目 AgentENV 在 7 月 23 日创建后快速获得关注，定位是“Running agent environments at scale”，用于大规模运行 agent 环境，支撑 Kimi K3 的 agentic RL training。项目强调 Firecracker microVM、OCI 镜像按需加载、快照恢复、环境 fork、S3/分布式文件系统持久化等能力。  
链接：https://github.com/kvcache-ai/AgentENV

**为什么重要**  
Agent 真正难的不是让模型说“我会执行”，而是让它在可重复、可隔离、可回滚的环境里大量试错。AgentENV 的走红说明行业开始补“训练与评测环境”这一层基础设施：有了环境快照和 fork，才能并行跑任务、做强化学习、复现实验失败。OpenClaw 这类本地执行系统也会遇到类似问题：每次工具调用都应可追踪，每个长任务都应能恢复。

**Zoe点评**  
看多 Agent 基础设施，优先级上调。对 Jamie 来说，AgentENV 不一定要直接使用，但它代表一个产品判断：Agent 生态下一阶段的机会不只是“做一个助手”，而是做任务环境、评估集、回滚、权限、审计这些底座。OpenClaw 可以把“稳定执行”作为差异化，不要被纯 UI 助手带偏。
