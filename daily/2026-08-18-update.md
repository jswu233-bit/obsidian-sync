## 🤖 AI新闻板块

### 1. DeepSeek Harness 把 agent 战场从模型能力直接推到运行时
- 发生了什么：[@op7418](https://x.com/op7418/status/2089631356062146981) 今天又转出了一条只给链接的帖子，和前几天围绕 DeepSeek Harness 的热度连在一起；同时公开 X 讨论里，DeepSeek Harness、Codex、Cursor、OpenCode、Pi 这批工具已经被放在同一张“agent 运行时”清单里比较。
- 为什么重要：这说明开发者关注点已经不是“谁的模型聪明”，而是“谁的 harness、插件、会话、日志和恢复更像真工作台”。对产品判断来说，这比单纯 benchmark 更接近真实采用。
- Zoe点评：**看多 harness 层，短期继续上调 DeepSeek Harness 的优先级。** 这类东西的价值不在 demo，而在能不能把长任务跑稳、跑断后继续接上。

### 2. 成本战已经从“每百万 token 多少钱”变成“每个任务要烧多少轮”
- 发生了什么：[@gkxspace](https://x.com/gkxspace/status/2089657305977823549) 今天直接把争论点从单价拉回到 token 效率：便宜模型未必省钱，因为可能会多跑很多轮；贵模型如果更快收敛，整体反而更便宜。
- 为什么重要：这对 AI 编程、agent 工作流和内容自动化都是真问题。产品的真实成本不是报价单，而是任务轮数、返工次数、工具调用和人工介入。
- Zoe点评：**看空只比标价的模型讨论。** 后续评估模型时，优先看总任务成本和收敛速度，不要被“更便宜”这三个字带偏。

### 3. GUI 电脑操作正在进入“手机指挥桌面”的阶段
- 发生了什么：[@dotey](https://x.com/dotey/status/2089590302910587116) 今天分享了豆包在手机端指挥电脑端 Agent 的使用方式，重点是跨设备接管、电脑资源复用、以及 GUI 操作不打断用户自己的活跃任务。
- 为什么重要：这类能力一旦做顺了，Agent 就不再只是命令行工具，而会变成跨终端的执行层。对零售、运营、资料整理和内部工具操作，意义很直接。
- Zoe点评：**看多电脑接管型 agent，但只看能形成稳定工作流的实现。** 真正值钱的是“设备资源复用 + 任务可插话 + 结果可验证”，不是花哨演示。

- Zoe点评：**看多团队协作型 agent 底座，看空纯个人爽感工具。** OpenClaw 后续要盯的重点是审计、回退、任务归属和多会话协同。
